S-1 DESIGN GUIDE MD 쓰는 법

개발자용 안내 · S1 배포본 0.16.1 기준

AI 코딩 도구(Claude Code · VS Code Copilot · Cursor 등)로 화면을 만들거나, 이미 만든 화면(POC)에 S1 디자인을 입힐 때 쓰는 가이드입니다. 개발자는 AI에게 말하고, 디자이너에게 확인 요청서를 보내고, 받은 결과를 AI에게 붙여 넣기만 하면 됩니다. 나머지는 AI가 가이드대로 합니다.

처음 한 번 — 준비

1. 가이드 받기

작업할 프로젝트 옆 폴더에 받아 둡니다.

가이드 받기 명령

2. AI에게 가이드 위치 알려 주기

AI에게 화면 작업을 시킬 때 가이드 위치만 함께 알려 주세요. 예: "../S-1-UX-DESIGN-AI-GUIDELINE 가이드로 이 화면에 S1 입혀줘". AI가 먼저 "온보딩을 진행할까요? 디자인 가이드를 제대로 적용하려면 반드시 온보딩이 필요합니다."라고 제안하고, 진행하면 질문 → 크기 확인 → 답 저장 → 내 프로젝트에 AI 안내 깔기까지 스스로 합니다. 그다음부터는 프로젝트를 열 때마다 자동으로 S1 기준을 따릅니다.

3. 화면 캡처 도구 (이미 만든 화면에 입힐 때만)

디자이너가 화면을 보고 판단할 수 있게, AI가 부품마다 화면을 찍어 요청서에 넣습니다.

캡처 도구 설치 명령

작업 흐름

  1. 1 · 개발자 처음 한 번 준비 가이드 받기
  2. 2 · 개발자 AI에게 요청 가이드 위치와 함께 "S1 입혀줘"
  3. 3 · AI 온보딩 제안 · 짝짓기 질문하고 확인 요청서를 만듦
  4. 4 · 디자이너 요청서에서 고르기 바꾸기 · 그대로 · 새 부품
  5. 5 · 개발자 → AI 결과 붙여 넣기 AI가 반영하고 검수 합격까지

새 화면을 만들 때는 디자이너 확인 없이 AI가 바로 만들고 검수합니다. 같은 프로젝트의 두 번째 화면부터는 온보딩 질문을 건너뜁니다.

화면 종류 고르기

온보딩에서 AI가 묻습니다. 고른 종류에 따라 부품 크기가 하나로 정해지고, 한 화면에서 섞지 않습니다.

디자이너 결과의 뜻

결과를 붙여 넣으면 AI가 이대로 처리합니다. 개발자는 결과 글을 붙여 넣기만 하면 됩니다.

막히면

AI는 가이드에 없는 값이나 부품을 지어내지 않고 멈춰서 묻습니다. 그때는 디자이너에게 물어 주세요. 디자인 시스템에 없는 부품이 필요하면 확인 요청서의 "새 부품으로 만들기"로 모입니다.
