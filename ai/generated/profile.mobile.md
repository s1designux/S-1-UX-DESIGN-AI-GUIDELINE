# 모바일 화면 — 이 크기만 씁니다

> 자동 생성물 — 손으로 고치지 마세요. 기준을 바꾸려면 `ai/rules/usage-profiles.json` 을 고치고 `npm run ai:scope` 를 돌립니다.
> 배포본 0.13.16 (2026-09-29 판) 기준.

이 화면은 **모바일 화면** 입니다. PC 기준은 이 화면과 관계가 없습니다.
배포본 예제(`ui-library/dist/examples/`)를 붙인 뒤 **`data-size` 값만 아래 표대로 바꿉니다.** 예제에 적힌 크기를 그대로 두지 않습니다.

## 1. 화면 맨 바깥에 한 번 적습니다

```html
<body data-s1-break="mobile">   <!-- 모바일은 손가락 기준 높이 48 하나 -->
```

모바일에는 밀도 단어(`data-s1-density`)를 적지 않습니다. 예제에 `data-break` 가 있는 부품은 모두 `data-break="mobile"` 로 적습니다.

## 2. 부품별 크기

| 부품 | 크기 |
| --- | --- |
| 버튼 `button` | `lg` (48) |
| 입력칸 `input` | `md` (48) |
| 선택 상자 `select` | `md` (48) |
| 칩 `chip` | `sm` (30) |
| 필터 칩 `filter-chip` | `md` (30) |
| 날짜 선택 `date-picker` | `md` (48) |
| 시간 선택 `time-picker` | `md` (48) |

## 3. 모바일에서 쓰지 않고 바꿔 쓰는 것

| 쓰지 않는 부품 | 대신 쓰는 것 |
| --- | --- |
| 멀티 토글 `multi-toggle` | 라디오 또는 체크박스 — 모바일에서 여러 값 중 고르는 자리는 멀티 토글 대신 라디오(하나 고르기)나 체크박스(여러 개 고르기)를 쓴다. |
| 드롭다운 목록 `dropdown` | 바텀시트 — 모바일에서 목록을 띄울 때는 드롭다운 대신 아래에서 올라오는 바텀시트를 쓴다. |
| 표(줄 높이) `table` | PC 전용입니다. 같은 모양 줄이 반복되면 `list-row` 를 씁니다. |

선택 상자·필터 칩 예제 안에 들어 있는 드롭다운 목록은 예제 그대로 둡니다. 드롭다운을 화면에 **따로** 띄우지 않는다는 뜻입니다.
