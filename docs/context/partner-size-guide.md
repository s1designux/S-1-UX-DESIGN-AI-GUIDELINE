**불일치 발견:** 가이드 생성 문서(profile.*.md, profiles.pc.html, scope.json 높이표)는 PC 입력칸·선택 상자·날짜·시간 `md` 를 48로 적지만, 배포본 부품은 PC에서 `md` 를 44로 그린다(48은 모바일 값). 협력사 페이지는 실제로 그려지는 44로 적었다. 가이드 문서 쪽 표기를 고칠지는 river 결정 대기.
