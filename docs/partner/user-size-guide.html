S1 디자인 가이드 · 협력사 안내

사용자용 PC 화면, 부품 크기는 이렇게 조합합니다

S1의 사용자용 화면에서는 같은 버튼이라도 놓이는 자리에 따라 크기가 달라집니다. 이 페이지는 어느 자리에 어떤 크기를 쓰는지 실제 S1 부품으로 보여줍니다.

먼저 세 가지만 기억하세요

크기는 자리가 정합니다

부품마다 크기가 하나로 정해져 있지 않습니다. 같은 입력칸도 등록 폼에서는 44, 검색 줄에서는 34입니다.

자리는 다섯 가지입니다

폼·상세 본문, 페이지 제목 줄, 검색·필터 줄, 표 칸 안, 팝업 본문. 아래 예시 화면에 색으로 구분해 두었습니다.

크기는 항상 적습니다

예제 코드를 붙인 뒤 크기 값만 이 기준대로 바꿉니다. 예제에 적힌 크기를 그대로 두지 않습니다.

코드에서 자리를 알려주는 법

다섯 자리 중 두 곳만 직접 표시합니다. 나머지는 위치를 보고 자동으로 정해집니다.

화면 맨 바깥

맨 바깥 요소에 data-s1-density="wide" 를 한 번만 적습니다. 크기를 빠뜨린 부품이 있어도 넓은 쪽으로 맞춰 주는 안전망입니다.

페이지 제목 줄

화면 제목, 제목 옆 버튼, 페이지 탭을 함께 감싸는 요소에 data-s1-zone="header" 를 적습니다.

검색·필터 줄

조건 부품과 조회 버튼을 바로 감싸는 요소에 data-s1-zone="filter" 를 적습니다. 표까지 감싸는 큰 영역에는 적지 않습니다.

폼 · 표 · 팝업

따로 적지 않습니다. 표시가 없는 곳은 폼·상세 본문, 표 안은 표 칸, 팝업 안은 팝업 본문으로 봅니다.

입력칸 라벨

라벨은 부품 위에 별도 글자로 올리고 간격 8을 둡니다. 라벨에 id 를 주고, 부품 맨 바깥 요소에 aria-labelledby 로 연결합니다.

<!-- 화면 맨 바깥 -->
<body data-s1-density="wide">

  <!-- 페이지 제목 줄 : 버튼 xsm · 탭 sm -->
  <div data-s1-zone="header">
    <h1>출입 기록</h1>
    <button data-s1-component="button" data-variant="primary" data-size="xsm">…</button>
    <div data-s1-component="tab" data-size="sm">…</div>
  </div>

  <!-- 검색·필터 줄 : 입력칸·버튼 xsm · 칩 md -->
  <div data-s1-zone="filter">
    <div data-s1-component="input" data-size="xsm">…</div>
    <button data-s1-component="chip" data-size="md">…</button>
    <button data-s1-component="button" data-size="xsm">조회</button>
  </div>

  <!-- 표 : 줄 md · 칸 안 버튼 xxsm -->
  <div data-s1-component="table" data-size="md">… data-size="xxsm" …</div>
